# GH-600 Agentic AI Developer Training Quiz

A small browser-based practice quiz for the **GitHub Certified: Agentic AI Developer (GH-600)** study notes.

- Questions are added only after the matching Microsoft Learn unit has been completed.
- Questions can have one or more correct answers.
- Results are saved in browser local storage.
- Incorrect answers show an explanation and the relevant Microsoft Learn source.

## Run locally

1. `npm install`
2. `npm run dev`

Use `npm run build` to validate a production build.
